# Einstein knowledge pack

This is a small, local, source-linked demonstration pack—not a comprehensive or independently reviewed biography. `bio/` contains sourced lifespan and institutional dates; `science/` contains three high-level claims summarized from the Nobel biographical record; `quotes/` contains a separate disputed-attribution example; and `civic/` is intentionally empty. Source metadata and known limitations are in `provenance/sources.json`.

The runtime does not fetch these sources. All quote records must retain their `VERIFIED`, `DISPUTED`, or `UNSOURCED` status and linked provenance. Do not treat an empty category as permission to invent facts.
