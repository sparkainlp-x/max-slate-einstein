# Roadmap

The project favors evidence quality and narrow scope over answer volume. The following are design targets, not commitments or current capabilities.

| Priority | Target | Evidence required before claiming completion |
|---|---|---|
| 1 | Expand source-linked biographical and scientific facts | Scholarly and primary-source review; claim-level provenance and counterevidence where relevant |
| 2 | Improve quote verification | Critical-edition or archival source locators; reviewer sign-off; uncertainty labels retained |
| 3 | Strengthen routing and refusal tests | Carefully designed benign/adversarial cases, multilingual test plan, false-positive/false-negative reporting |
| 4 | Independent safety, privacy, and security review | Published scope and findings; documented remediation; no claim of completeness |
| 5 | Accessibility and learning evaluation | Screen-reader and keyboard tests, inclusive learner review, and documented limits |
| 6 | Consider a richer answer pipeline only if evidence-backed | No unrestricted browsing; claims must remain source-attributed and historically bounded |

No long-term user memory is planned by default. Any proposal to persist personal data, expand the persona’s authority, or present the simulation as historically authentic would require a separate product and user-intent decision.
